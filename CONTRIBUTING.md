# Contributing

Thanks for helping with MegaBite.

## Run it

```
claude --plugin-dir .          # play your local copy
claude plugin test .           # run the tests
claude plugin validate .       # check the manifests
```

## Ideas welcome

- New fish ideas
- Bug reports: what you pressed, what happened, your Claude Code version

## Pull requests

Keep them small, and make sure `claude plugin test .` passes. CI runs it on every PR.
